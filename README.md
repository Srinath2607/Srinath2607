Autonomous Solar-Powered UAV Delivery System Optimized via Soft Actor-Critic Reinforcement Learning

  <img src="https://readme-typing-svg.herokuapp.com?font=Space+Grotesk&weight=600&size=20&duration=3000&pause=1200&color=00D9FF&center=true&vCenter=true&width=1000&lines=Presented+at+CVR+2026+%7C+NIT+Goa;Solar-Powered+UAV+Delivery+System;Soft+Actor-Critic+Reinforcement+Learning;Energy-Aware+Planning+%7C+Obstacle+Avoidance+%7C+Adaptive+Control;94%25+Success+Rate+%7C+17.6%25+Energy+Efficiency" />
</p>

<p align="center">
  <img src="https://img.shields.io/badge/Reinforcement%20Learning-020617?style=for-the-badge"/>
  <img src="https://img.shields.io/badge/Soft%20Actor%20Critic-003B73?style=for-the-badge"/>

</p>

> Developed a solar-powered UAV delivery system using **Soft Actor-Critic Reinforcement Learning** with real-time obstacle avoidance, energy-aware planning, and adaptive control using **Gazebo, ROS, and NVIDIA Jetson Nano**. The system achieved **17.6% energy efficiency**, **14.8% lower latency**, **94% success rate**, and **PSI = 0.91**, outperforming A*, GA, DQN, and PPO.
